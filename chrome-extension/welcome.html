60FPS Engine

Zero-Jitter Interpolation

Decouples the progress bar from the background script's polling. Uses requestAnimationFrame to smoothly glide between syncs, eliminating rubber-banding and lag.

Platform Isolation

3 Dedicated Media Engines

Uses Apple's native MusicKit SDK for Apple Music, stable `data-testid` selectors for Spotify, and intelligent audio filtering for YouTube/YT Music.

Dual-Source Caching

LyricsPlus & LRCLib

Fetches from both providers simultaneously using Promise.allSettled, merges the data, and caches it to localStorage for 24 hours. Zero redundant API calls.

Universal Teleport

Cross-Tab Picture-in-Picture

Overcomes Chromium's strict gesture requirement by silently teleporting to the media tab, triggering the standard HTML5 API, and instantly teleporting back—all in milliseconds.
